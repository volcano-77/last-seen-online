# phase-01 与 phase-02 首段页面可达性矩阵

本文件是开发资料，玩家界面不加载它；不是剧情事实来源。剧情仍以 `story-bible.md` 为准。标题中的城市、日期、人物年龄仍读取已有 provisional 变量，本轮未将其确认为正式设定。

## 判读规则

- **普通导航**指渲染后的站点链接，包括用户名、真实发帖活动、博客目录、文章前后篇、来源链接；不把知道 URL 后在地址栏手输当作首次发现。
- **站内搜索**指生活论坛 / 校园 BBS 目前实际提供的搜索框。新闻、博客、个人资料没有独立站内搜索界面。
- **南城搜索**覆盖公开正文、回复、用户名、属性与旧索引。首页默认不索引，只有明确 `searchIndexed: true` 的孤立博客首页例外。快照、缓存、失效网址不混入全网结果；好友内容不索引。
- **存档**表示有真实 `snapshot` 的历史载体，可由网页存档查旧网址 / 标题找到，或在已打开的副本中点击。普通网页不会由存档服务复制成第二份结果。
- “副本内”表示必须先发现存档工具；不是从三个主站的当前导航进入。工具前置与访问问题持续读取 v6 进度，记录正文仍读最新 Case。
- `normalNavigation: false` 关闭未访问孤立页的外站普通入口；在已发现网站内部，网站名称和博客目录仍正常工作。历史、已有标签、真实最近访问与记录来源允许重访。`searchIndexed` 独立控制索引。
- 回声首页另有 `firstVisitFromPageId: echo_unavailable`；其余回声快照、刘佳缓存、存档服务和回声孤立资料设置 `requiresTool: archive`。首次进入 `echo_home` 才学会工具。旧 v6 存档中的已经发现状态保留，不强迫重走。
- “主线”以现有 F01～F12 / R01～R06 是否需此页的事实为准。“入口”是正常发现路径，不表示每次访问都必须经过它。

## 工具分工与重叠

- **首次只有南城搜索**：赵妍博客站点（显式索引首页及公开日志）与 `member_10`～`member_13` 的现有孤立资料。`member_13` 还要求先发现存档工具。赵妍博客是本轮主线实际使用的孤立索引入口，其余资料不是主线必需。
- **只有普通导航而不被搜索 / 存档索引的内容**：`echo_account_posts`、`summer_album`、`member_1`～`member_9`；工具 / 站点目录也不伪装成搜索结果。相册还保留自己的访问问题与图片比对用途。
- **正常导航并可搜索**：当前论坛主题、资讯报道、夏天会员资料与公开博客日志。命中同一当前帖子是合理重叠：站内搜索仅本站正文 / 回复，全网搜索跨站并覆盖孤立旧索引；二者不是重复主页列表。
- **浏览器历史 / 最近访问**只返回真实保留的标签历史，不作为未发现内容的索引。最近访问按标签最近使用顺序，再按该标签当前历史位置向前列出，去重到六项；已关闭标签不伪造记录，历史恢复保留该条目的滚动与局部状态。
- **网页存档**只处理实际历史副本，不返回当前新闻 / 博客的正文结果。回声的唯一首次恢复入口与刘佳早期缓存提供其独立用途。
- **记录**只保留已发现事实、用户主动选取的短摘句和已建立结论；不是搜索结果或页面目录。来源跳转只为回看已阅读内容。
