# 案件 01：《寻人启事》剧情事实档案

> 状态：设计中的唯一剧情事实来源。案件页面、谜题、图片与代码实现须以本文件为准。未定事项只能保留为占位，不得为了交互方便自行补完。本文不代表已经完成的游戏内容。

## 1. 核心设定与边界

- 时间背景约为 2009 年，呈现中国早期互联网环境；具体年份、城市和人物年龄尚未确定。
- 回声寻人网表面是公益寻人网站，正常业务确实帮助家属寻找失踪者。负责人是梁志诚。
- 梁后来发展出收费的灰色业务“特殊寻访”：替客户寻找主动躲藏的人，出售工作地点、大致住处、活动区域、作息、联系方式、近期照片等**定位结果**，不承诺绑架或抓回。
- 假寻人启事是低成本定位工具。目标往往尚未失踪；普通网友基于善意留下目击信息，梁再拼接这些信息。
- 核心谜面：**寻人帖的发布时间早于当事人后来公开确认的失踪时间**。同一机制既能帮助寻找失踪者，也能暴露故意不想被找到的人。
- 整体为现实主义、本格推理式因果；无超自然、邪教、神秘组织、万能黑客、器官交易或人口贩卖设定。每条信息要能追溯来源，后期证据应能重新解释前期证据，人物不能为推动谜题突然降智。

## 2. 人物与因果

### 梁志诚

- 梁通过网站、公开网络资料、网友目击回复拼接零散信息，并用少量受其控制的外勤确认关键地点和身份。他并非全知，也不是专业跟踪者，平时尽量不亲自参与现场行为。
- “特殊寻访”的绝大多数订单能完成：客户付款，梁交付位置资料，交易结束。客户之后的行为不一定由梁负责，因此这门业务具有真实商业价值。
- 客户并非都忠诚，也并非都知道梁使用了违法方法；部分灰色客户不愿报警。梁保存部分客户的付款、委托、聊天或虚假身份材料，形成互相制衡。
- 陈雨触及核心秘密后，梁亲自出现在陈雨事件现场。这是高风险例外。

### 许宁

- 许宁曾是“特殊寻访”的目标，当时正在躲避长期暴力、控制她的前男友。前男友谎称她精神状态异常、与家人失联，委托回声寻人网寻人。
- 梁发布寻人信息，网友提供目击回复，梁**成功定位并把位置交付**前男友。前男友找到许宁并实施严重暴力。梁在这一单确实完成了委托。
- 许宁后来主要针对前男友的暴力和骚扰报过警，但起初无法证明网站与前男友存在非法交易。她为查清自己为何被找到，逐渐查到梁。
- 梁先以帮助隐藏新地址、拒绝以后寻找她的委托等条件，让她做越来越越界的小事：确认人在不在指定地点、拍照、短程跟随、确认工作地点或住址、递送物品。
- 许宁不是专业侦探；会跟丢、拍糊，也不敢进入私人区域。梁负责信息拼接，许宁只是有限的外勤确认工具。
- 梁逐渐掌握她违法跟踪、进入他人区域、领取报酬等把柄，反复以“再做最后一次”“这一单结束就不用你了”控制她。许宁逐渐相信出现替代外勤后自己可能自由；**这只是梁的谎言，并非业务制度**。
- 许宁逃避前男友、调查回声寻人网之后，梁以“替她处理骚扰、旧寻人信息以及以后可能出现的搜索请求”为理由，逐渐取得她旧邮箱的控制权。他改过安全设置，设置自动转发 / 代收，使许宁不再拥有完整独立控制权。这是普通账户控制与邮件规则，不是万能黑客入侵。

### 陈雨

- 陈雨是大学校园论坛版主。她发现“刘佳失踪”帖，却在当天见过刘佳；她利用版主可见的来源信息，发现发帖账号与回声寻人网有关。
- 她查旧帖，逐渐找到多起“寻人帖早于后来公开确认的失踪时间”的案例，最终整理出约九例的表格，其中包括许宁。
- 为核实许宁案例，她给许宁以前留下的旧邮箱发送邮件，并附案例截图，主题语义为“关于你以前那张寻人启事”。旧邮箱已被梁控制，存在自动转发 / 代收。**梁直接看到这些材料，明确知道陈雨发现了规律**；不是靠猜测她的社会关系。发件记录、邮箱设置通知与许宁自保说明必须组合验证，具体要求见第8节。
- 梁不知道陈雨是否备份、告诉老师、联系记者、报警或发给朋友。陈雨突然死亡会促使人检查设备，可能直接暴露九例关联，所以梁首先需要确认她掌握多少、资料有无外传。
- 陈雨先看到自己的寻人启事，此时她并未失踪；帖下陌生网友已提供西门、宿舍楼、食堂等实时目击回复。随后她收到六张生活照片，其中**至少一张**须证明对方知道她正在调查提前寻人帖，例如她整理案例表格时的背影。威胁含义是“知道你在哪里，也知道你正在查什么”。
- 她以受惊学生的合理方式应对：换住处、备份材料、寻找可信任的人、考虑报警，以及想查清许宁与梁的关系。她没有正式接到并“拒绝”某个任务。

### 王曼

- 王曼是陈雨信任的年长学姐 / 校友，已经毕业，当时在南城资讯网本地 / 社会新闻线做实习记者，有基础采访、公开资料核查和证据保存意识。她不是专业侦探，不会黑客入侵，也没有警方权限；“南城”仍是暂定城市名。
- 陈雨出事**之前**已把部分调查资料、截图或整理结果发送 / 备份给王曼。本轮锁定的是材料已外传，不再断言完整调查资料全部送达。邮件语气应日常，例如请学姐看附件；附件可呈现为“论坛旧帖整理.xls”，不必戏剧化，具体文件与所含内容待设计。
- 梁在陈雨出事**之后**检查她的设备、邮箱或已发送记录，才第一次发现王曼已收到材料；王曼此时才成为新的风险目标。不得把她写成梁预先知道的下一目标。
- 王曼收到的六张威胁照片来自公开资料、网友目击或旧照片、梁整理的网络信息、陈雨发件截图，以及许宁拍摄的少量现场确认照片。它们的画质、分辨率和来源不同；许宁不能被写成全天跟踪王曼的高手。
- 威胁必须表明梁知道她收到陈雨材料、知道其真实生活范围和正在做的事，并知道陈雨已经出事。王曼仍会备份、求助或咨询他人，不会仅因普通偷拍就立刻屈服。
- 038—043使用普通冲印袋寄给王曼，袋内附简短打印纸，语义为“陈雨留给你的东西，不属于你。到这里为止。”不写夸张恐吓台词。袋上保留“城西照相馆”、普通订单编号和冲印时间；具体寄件人、递送服务、编号及时间值未定，不把包装标记设计成暗号。
- 王曼从六张的来源、分辨率、压缩与设备痕迹差异判断：它们由公开网页、公开活动、网友目击、网络图片和少量现实确认聚合而来，并非一个专业跟踪者连续偷拍。该判断是理解“特殊寻访”机制的前置，不单独证明收费或全部业务规模。
- 王曼携照片与冲印袋到店说明威胁情况，店员在合理范围内协助查询旧订单，经许可复制订单信息、必要文件列表及对应预览缓存。她保存副本、识别037后联系许宁，建立多重备份；**玩家最终经南城搜索旧索引 → 失效记者工作页 → 网页存档恢复资料目录取得可恢复的调查材料**，不由某人凭空送来全部资料。
- 王曼最终主动离开暂称南城的城市，停用旧账号、切断公开实时活动、降低公开可定位性；她没有被绑架、没有死亡，不是另一宗传统失踪受害者。离开前分散备份、告知少数可信任的人并保留能证明自愿离开的信息，具体载体与目的地不补写。详见第9节及 [wang-man-investigation.md](wang-man-investigation.md)。

## 3. 陈雨事件：已确定的约见、受伤与死亡

### 约见与梁的介入

1. 陈雨调查多起“寻人启事早于实际失踪”的异常案例，并主动联系许宁。
2. 许宁在梁志诚的控制 / 施压下答应见陈雨，告诉她自己知道旧寻人启事的问题，但要求线下谈。陈雨认为约见对象只有许宁。
3. 见面地点是**城西一栋老商业楼二层的小茶座**。这是普通公共场所，不是废弃建筑、地下室或预设犯罪现场。
4. 梁随后亲自出现。陈雨已接近“特殊寻访”核心，梁不知道她掌握多少、是否有备份、是否发给别人。他最初的目的不是杀陈雨，而是确认信息范围、找出备份去向、取走手机及相关资料、阻止继续调查。

### 争抢、重伤与主动不救

1. 谈话失控后，陈雨试图离开。在商业楼楼梯口，双方围绕手机 / 包发生争抢；梁试图拦住陈雨，拉住她或她的包。
2. 陈雨失去平衡，摔下**半层楼梯**，头部受到严重撞击。这不是预谋杀人，也不是事先准备好的袭击方式；不得擅自加成蓄意推下楼梯。
3. 陈雨摔倒后仍有生命迹象，梁确认她还活着，却没有立即求救。许宁想求助或报警，梁阻止。
4. 梁优先取走 / 查看陈雨手机、搜查她的包、查找调查材料，并确认她是否把内容发给其他人。这是他在事件中最关键的主动选择。随后梁与许宁离开。
5. 陈雨被后来经过的商业楼工作人员发现并送医，因严重颅脑损伤，**在两天后死亡**。
6. 公开信息最初将事件描述为“年轻女子在商业楼楼梯摔伤，后经抢救无效死亡”，或语义等价的普通事故报道。报道中的事故表述不是对全部因果的最终认定。
7. 故事**不得断言立即求救就一定能够救活陈雨**。严重伤势与延误求救并存，保持现实的不确定性；梁的主动不救不能被抹去，也不能凭此把事件改写成预谋杀人。

### 王曼成为新的风险目标

- 陈雨出事之前，梁不知道王曼是重要人物，没有提前把她列为目标。
- 陈雨出事之后，梁通过她的手机、邮箱、已发送记录或文件痕迹，发现王曼可能持有外传副本。王曼此时才第一次成为新的风险目标。
- 陈雨事故发生前没有正式王曼特殊寻访任务。梁发现发件信息后才创建王曼相关调查 / 特殊寻访工作记录，其创建时间必须晚于事故。后续以043发件截图、038—043文件生成时间、内部任务创建时间组合验证；内部记录具体载体留给“梁交易证据线”设计，不得凭“梁知道了”就直接给玩家结论。

## 4. 照片、SD 卡与数字残留

### 037：上一宗事件的结尾

- 删除“任务完成确认照”设定。037是许宁**偷偷为自己留下保险**的原始照片，梁不知道它存在，也没有要求拍它。
- 许宁看到梁优先搜查资料而不是立即救人，第一次真正意识到所谓“最后一次”并不可信，也由此确认梁所说“只拿回材料、不会伤害目标”不可信，担心自己以后也可能成为被处理掉的人。她不是出于英雄主义，而是出于自保偷拍；037是她第一次真正背叛梁而保存的证据。
- **拍摄时点已定**：陈雨严重受伤之后、梁搜查她的手机 / 包期间。
- **画面至少须可识别**：陈雨的白色外套、红色钥匙圈、倒在现场的陈雨、敞开的包或散落物品、梁正在持有陈雨手机或翻找物品，以及梁的侧脸 / 三分之二侧脸。不能只剩无法辨认的人影。
- 037不能直接证明陈雨如何摔倒，不能单独证明梁故意杀人；可以证明梁在关键时间身处现场，以及陈雨重伤时他正在处理其设备 / 物品。
- 画质为低分辨率普通消费级数码相机照片：室内弱光，轻微运动模糊，但仍能通过其他资料识别人和物。具体像素与素材制作参数待设计，不再把整体可识别程度作为待定剧情。
- 原件保存在许宁自己使用的 SD 卡、相机自动生成的 **DCIM 目录**中，未被打印。梁不知道它存在。

### 038—043：下一宗事件的开始

- 陈雨出事后，梁发现王曼可能持有副本，整理针对王曼的六张威胁性照片 / 图像，让许宁负责打印。
- 六张来源混合，分配按下表锁定；不能表现为同一专业跟踪者连续偷拍。实际打印成实体威胁包，目的是让王曼知道对方知道她是谁、现实活动位置、陈雨给过她资料，并能继续搜集她的生活信息。
- 六张的分辨率、压缩痕迹、拍摄设备与时间来源不同，这些差异后续可用于数字取证；具体画面构图、属性数值与来源页面尚待设计。梁的能力核心仍是信息聚合、公开网络、群众目击与少量外部跑腿，不是专业全天候尾随或黑客能力。
- 梁把 038—043 复制到同一张 SD 卡的**独立打印目录**，没有浏览 DCIM，因此没有发现 037。打印目录的具体名称与完整文件名未锁定。
- 卡上因此有 037 原始照片与 038—043 六张待打印图片。许宁随机选择普通的城西照相馆，付现金，只要求打印后六张。
- 照相馆旧式图片软件**递归扫描整张存储卡**，七张均进入自动生成的缩略 / 预览缓存；实际订单只选择 038—043：**扫描七张、实际打印六张**。037未打印，却意外留下中等尺寸预览缓存，玩家后来才可能恢复它。这是普通旧软件的数字残留，并非有人故意放置证据。
- “照相馆收到七张、只敢洗六张，第七张太恐怖”的都市传说是错误解释。七张并非同一组：037属于陈雨事件结尾，038—043属于王曼事件开端；037与038之间才是真正的时间断点和后期反转。
- 陈雨先前收到的六张生活照片，与这里王曼收到的 038—043 六张照片是**不同组**，不得混同。

| 编号 | 正式来源 / 用途 | 仍不锁定的细节 |
| --- | --- | --- |
| 038 | 王曼公开个人网页 / 公开头像来源，指向她的身份 | 正式网页地址、头像构图 |
| 039 | 公开校园 / 活动照片，展示公开活动痕迹 | 具体活动、拍摄者与日期 |
| 040 | 基于网友目击或公共信息确认的近期位置 | 具体地点、目击来源与图像形式 |
| 041 | 许宁实际拍摄的一张低质量远距离照片 | 具体地点、时间与构图，不升级为专业尾随 |
| 042 | 住处 / 工作区域附近的现实照片或公共信息组合 | 在两个来源方向中的选择、具体区域与制作者 |
| 043 | 陈雨邮箱“已发送”记录截图，明确王曼是收件人、曾收到调查资料 / 附件 | 实际地址、主题、附件名和截图范围；不得泄露全部剧情答案 |

043必须足以让王曼意识到对方已查看陈雨的通信记录。它不是约九例表格的完整答案展示，也不能独自证明截图者身份、王曼任务的创建时间或梁何时首次知情。

### 城西照相馆与七扫六印反转

- 城西照相馆是普通第三方商家，与梁、回声寻人网没有组织关系。许宁选择普通小店，符合她作为被控制的外围执行者、希望减少固定痕迹的处境。
- 王曼凭普通冲印袋上的店名、订单编号与冲印时间找到店铺，亲自持照片说明威胁并核查。店员在合理范围内查旧订单，记录显示该次导入扫描七个图片文件，勾选 / 打印六个；店员不知道第七张的意义。
- 店铺当时仍保留该订单的临时工作目录 / 图片预览缓存。店主允许王曼复制订单记录、相关缓存与必要文件列表作为调查材料；不是老板一直秘密收藏案件证据，也不是玩家远程黑入商家。

### 9.4 多重备份与玩家资料入口

王曼建立自己电脑的工作副本、交由可信任编辑保管的实体数据盘、南城资讯网旧式“记者手记 / 个人工作页”中的网络资料目录。编辑仅为保管人，不扩展为主要角色、不命名，也不成为玩家拿盘的默认路径。网络目录不出现在资讯网正常首页导航。

记者工作页后来随网站改版下线，当前地址失效，但曾由南城搜索建立旧索引，也有网页存档可恢复的历史目录。玩家由独特用户名 / 文件名先找到消失入口，再用存档恢复历史内容；搜索只找入口，存档恢复资料，具体索引词、路径和必要文件保存范围未定。电脑、实体盘和网络目录是不同备份，不声称所有内容完全相同或整套敏感资料都曾公开。

### 9.5 主动离开与定位失败

王曼在离开前分散备份、告知少数可信任的人自己主动离开、停用旧账号并保留自愿离开的信息。她不再公开实时位置，同时留下不同方向的过时 / 干扰性公开线索。梁继续依赖公开信息、网友目击和寻人式众包，却得到互相冲突的位置，信息聚合模式第一次明显失败。

她理解公开网络信息会被用作定位武器，主动停止提供可靠实时数据；这不是超高科技反追踪，也不意味着删除全部旧历史。**王曼没有被杀、绑架或传统意义失踪**。不锁定离开目的地、最终新身份、梁后续法律结果或游戏ending画面；未来自愿离开信息和冲突目击的具体载体仍需设计。
