## 1. 身份、时间与玩家视角

- 王曼是陈雨信任的年长学姐 / 校友，当时在南城资讯网本地 / 社会新闻线做实习记者。能力限于基础采访、公开资料核查、来源比对和证据保存，不是侦探、黑客或具有警方权限的人。
- 本文按王曼实际行动的先后记录。玩家在更晚的时间通过历史资料回看和重建这条路径，不要求玩家代替她联系许宁、到店或与现实人物互动。
- 城市仍暂称“南城”；日期、年龄、账号、文件名、具体地点和文书参数未锁定。家属后来维权 / 诉讼与资料公开需要时间，不把公开资料写成事发当天已有，也不指定期间长短。
- 037为陈雨事件结尾，038～043为王曼威胁材料开端，编号连续不代表同一次任务。内部任务编号示例`S-031 / S-034 / S-037`属于另一套体系，具体值仍是变量。
- 每步“新结论”只列当时来源允许的认识，不自动转化为新游戏fact / conclusion ID。未来交互优先搜索、网页探索、图像细节、文件属性、日期比对、证据组合与缓存恢复，无长篇自由输入。

## 3. 事故时序的来源与证明分层

1. **公开取得**：陈雨家属针对商业楼 / 物业安全责任的民事维权或诉讼，公开裁判资料 / 案件摘要记载外围监控、发现与急救呼叫时间。具体公开形式未选定，不设计非法取得警方录像、不开放原卷宗或急救录音。
2. **固定外围顺序**：陈雨离开茶座 → 梁进入楼梯区 → 许宁附近出现 → 一段时间后二人离开、陈雨未同行 → 工作人员进入 / 发现 → 工作人员首次呼叫急救。精确分钟保持变量；记录须指向同一事件，校核时钟与覆盖范围。
3. **图像范围**：037支持在场身份与处理设备 / 物品，实际拉扯 / 跌落仍是盲区。不能将公开摘要想象成完整视频，也不把工作人员时间与监控摘要同出一份公开材料的情况算作两份独立证据。
4. **证言补充**：许宁解释生命迹象检查、优先找资料和阻止当时立即求助。必须逐项与图像、外围 / 离开 / 呼救时间核验；能相互支持的事实与仅有其陈述的细节分别记录。
5. **保留边界**：不能证明及时救援一定改变死亡结果；不锁定最终法律责任、警方 / 法院结果。不改变既定争抢失衡摔下半层楼梯、两天后死亡的canon。
