## 1. 身份、时间与玩家视角

- 王曼是陈雨信任的年长学姐 / 校友，当时在南城资讯网本地 / 社会新闻线做实习记者。能力限于基础采访、公开资料核查、来源比对和证据保存，不是侦探、黑客或具有警方权限的人。
- 本文按王曼实际行动的先后记录。玩家在更晚的时间通过历史资料回看和重建这条路径，不要求玩家代替她联系许宁、到店或与现实人物互动。
- 城市仍暂称“南城”；日期、年龄、账号、文件名、具体地点和文书参数未锁定。家属后来维权 / 诉讼与资料公开需要时间，不把公开资料写成事发当天已有，也不指定期间长短。
- 037为陈雨事件结尾，038～043为王曼威胁材料开端，编号连续不代表同一次任务。内部任务编号示例`S-031 / S-034 / S-037`属于另一套体系，具体值仍是变量。
- S只表示收费客户任务；王曼归事故后内部风险任务`R-XXX`，记录含创建时间、王曼代号、状态与少量处理备注，038～043不计收费样本。风险编号也不是游戏关系R01～R05。
- 玩家身份保持弱化，只重建旧资料，不安排专业职业或真实身份。历史上的王曼采访与玩家点击“递交复核材料”是两个时期的动作。
- 每步“新结论”只列当时来源允许的认识，不自动转化为新游戏fact / conclusion ID。未来交互优先搜索、网页探索、图像细节、文件属性、日期比对、证据组合与缓存恢复，无长篇自由输入。

## 3. 事故时序的来源与证明分层

1. **公开取得**：陈雨家属针对商业楼 / 物业安全责任的民事维权或诉讼，公开裁判资料 / 案件摘要记载外围监控、发现与急救呼叫时间。具体公开形式未选定，不设计非法取得警方录像、不开放原卷宗或急救录音。
2. **固定外围顺序**：陈雨离开茶座 → 梁进入楼梯区 → 许宁附近出现 → 一段时间后二人离开、陈雨未同行 → 工作人员进入 / 发现 → 工作人员首次呼叫急救。精确分钟保持变量；记录须指向同一事件，校核时钟与覆盖范围。
3. **图像范围**：037支持在场身份与处理设备 / 物品，实际拉扯 / 跌落仍是盲区。不能将公开摘要想象成完整视频，也不把工作人员时间与监控摘要同出一份公开材料的情况算作两份独立证据。
4. **证言补充**：许宁解释生命迹象检查、优先找资料和阻止当时立即求助。必须逐项与图像、外围 / 离开 / 呼救时间核验；能相互支持的事实与仅有其陈述的细节分别记录。
5. **保留边界**：不能证明及时救援一定改变死亡结果；E05在场处理设备与E06首次明确急救呼叫可由对应客观组合证明，E07检查生命迹象 / 阻止即时求助属于证言加外部材料强支持，不能独立还原全部过程。不改变争抢失衡、半层楼梯、两天后死亡的canon；后续司法新证据与玩家旧材料分开。

## 6. 来源登记与三个时间层

每项王曼保存资料登记：原创建者 / 原持有人、取得日期（变量）、取得方式与许可、原地址 / 文件关联、公开网页恢复或周提供副本或许宁副本或商家记录、后续备份位置。声明来源不是独立认证，必须和材料字段互证。玩家记录由系统引用这些来源，不要求填采访报告。

1. **历史调查**：王曼当时实际公开查询、到店获许可、与许宁合作、周许可提供。
2. **玩家考古**：独特词找到旧索引→失效页→存档恢复必要文件；须逐件确认实际抓取数据，无法恢复者不可加入结论必要输入。
3. **递交之后**：媒体重新核验来源、调查机关获得新设备 / 记录、编辑转达王曼安全。不可作为第2层尚未拥有的必需证据。

## 7. 收束：尊重主动离开

玩家自动材料包递交家属旧民事渠道与资讯网现存线索渠道后，正史推进复核、媒体验证、调查介入、新证据与梁被追责判刑，回声停运。许宁活着合作并承认参与工作，行为单独处理。

重新引起关注后，可信编辑只转达王曼“我安全。不要找我。”不披露现住处、新联系方式或新身份；编辑从保管人增加可信转达用途，仍不成为主角或玩家拿盘入口。递交前判断主动离开必须另有AT-49可读来源，不能用尚未发生的消息填补。
