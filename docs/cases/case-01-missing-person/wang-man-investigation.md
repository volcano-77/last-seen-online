## 3. 事故时序的来源与证明分层

1. **公开取得**：陈雨家属针对商业楼 / 物业安全责任的民事维权或诉讼，公开民事案件摘要记载外围监控、发现与急救呼叫时间。已选公开案件摘要，引用外围监控和急救受理时间并说明覆盖 / 时钟校核；不开放原卷宗、原始警方录像或急救录音。
2. **固定外围顺序**：陈雨离开茶座 → 梁进入楼梯区 → 许宁附近出现 → 一段时间后二人离开、陈雨未同行 → 工作人员进入 / 发现 → 工作人员首次呼叫急救。精确分钟保持变量；记录须指向同一事件，校核时钟与覆盖范围。
3. **图像范围**：037支持在场身份与处理设备 / 物品，实际拉扯 / 跌落仍是盲区。不能将公开摘要想象成完整视频，也不把工作人员时间与监控摘要同出一份公开材料的情况算作两份独立证据。
4. **证言补充**：许宁核认王曼的采访文字摘录，解释生命迹象检查、优先找资料和阻止当时立即求助。必须逐项与图像、外围 / 离开 / 呼救时间核验；能相互支持的事实与仅有其陈述的细节分别记录。
5. **保留边界**：不能证明及时救援一定改变死亡结果；E05在场处理设备与E06首次明确急救呼叫可由对应客观组合证明，E07检查生命迹象 / 阻止即时求助属于证言加外部材料强支持，不能独立还原全部过程。不改变争抢失衡、半层楼梯、两天后死亡的canon；后续司法新证据与玩家旧材料分开。
